# Personal Branding & Impactful CV

A self-contained, editable HTML presentation based on the 12-slide template created from the supplied Personal Branding & Impactful CV PDF.

## Open the presentation

Download `index.html` and open it in a browser. No installation, server, or internet connection is required.

- Use the arrow buttons or Left/Right keys to navigate.
- Choose **Edit text** to replace the placeholders. Choose **Finish editing** to resume keyboard navigation.
- Choose **Save HTML** to download a copy containing your edits. Changes are not automatically saved to GitHub or the original file.
- Choose **Print / PDF** to export all 12 slides. Use background graphics and no browser headers or footers for best results.
- Choose **Full screen** for presenting.

The design uses orange covers, serif headings, white backgrounds, grey content panels, editable tables, and a dark review slide. Fonts fall back to local serif and sans-serif fonts when the original face is unavailable.
